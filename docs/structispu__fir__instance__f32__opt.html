Detailed Description

Floating-point FIR filter (optimized) instance structure.

The FIR filter (optimized) internally uses the hardware circular buffer accelerator. The accelerator registers must be saved and restored by the user if the execution of the filter is interrupted and the accelerator is needed for other purposes during the interruption.
